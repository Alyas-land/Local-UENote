# 🎮 Local UENote

A lightweight local note-taking application designed for:

- Unreal Engine learners
- Game developers
- Programmers
- Quest Designers

Local UENote helps developers organize technical notes, code snippets, gameplay ideas, and quest documentation in a simple local workspace.

---

# ✨ Features

## 📝 Note System
- Create and manage local notes
- Organize game development documentation
- Store gameplay and design ideas

## 💻 Code Support
- Syntax Highlighting
- Live Preview while editing notes or code
- Fast local workflow for technical documentation

## 🔍 Search Support
- Text highlighting using Mark.js
- Easy navigation between notes

## 🗄️ Local Storage
- SQLite database
- Fully local application
- Lightweight and simple architecture

---

# 🛠️ Technologies Used

## Backend
- Python
- Flask

## UI
- Bootstrap

## Libraries
- Highlight.js
- Mark.js

## Database
- SQLite

---

# 🎯 Use Cases

- Unreal Engine learning notes
- Quest writing and narrative documentation
- Gameplay system documentation
- Personal game development wiki
- Code snippet management

---

# 🚀 Goal

The goal of this project is to create a lightweight local workspace for game developers and designers to document ideas, write technical notes, and manage development knowledge efficiently.

---

# 📌 Status

Currently under development.
